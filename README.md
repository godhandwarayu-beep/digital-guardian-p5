# ผู้พิทักษ์ดิจิทัล ป.5

เกมผจญภัย 3 มิติ สำหรับทดสอบความรู้หลังเรียน ใช้กับรายวิชาเทคโนโลยีเพื่อชีวิตประจำวัน 5 ชั้นประถมศึกษาปีที่ 5 ภาคเรียนที่ 1/2569
เกมมี 40 ด่าน ตรงกับแผนการจัดการเรียนรู้ 40 แผน (แผนละ 1 ชั่วโมง) ใช้เล่นประมาณ 10 นาทีหลังเรียน ก่อนครูสรุปบทเรียน

ครูผู้สอน: นายวรายุ ศรีบุบผา · โรงเรียนวัดเชิงท่า · สพป.พระนครศรีอยุธยา เขต 2

## วิธีเล่นในแต่ละด่าน
1. ผู้เล่นรับบทอัศวิน มีภูตบิตตี้เป็นผู้นำทาง เดินสำรวจตามลำแสงสีทอง ระหว่างทางเก็บเพชรความรู้ (มีทั้งหมด 7 เม็ด แต่ละเม็ดบอกสาระสำคัญของบทเรียน)
2. คุยกับผู้ท้าประลอง 3 คน แต่ละคนเรียกปีศาจออกมาประลอง ต้องตอบคำถาม 2 ข้อ (แบบโปเกม่อน) ตอบถูกอัศวินจะฟันดาบใส่ปีศาจ ตอบผิดปีศาจจะโจมตีกลับ
3. เมื่อชนะครบ 3 คน ประตูมิติจะเปิด ให้เดินไปลานบอส แล้วตอบคำถาม 4 ข้อเพื่อปราบจอมปีศาจ
4. ข้อไหนตอบผิด เกมจะเฉลยพร้อมคำอธิบาย และให้ตอบข้อนั้นใหม่อีกครั้ง (คะแนนนับจากการตอบครั้งแรกเท่านั้น)
5. จบด่านจะแสดงคะแนนเต็ม 10 ดาว 0–3 ดวง (9–10 ข้อได้ 3 ดาว, 7–8 ได้ 2 ดาว, 5–6 ได้ 1 ดาว) และรายการข้อที่ต้องทบทวน

## ปุ่มควบคุม
- คอมพิวเตอร์: เดินด้วย W A S D หรือลูกศร (กด Shift ค้างเพื่อวิ่ง) หรือคลิกที่พื้น · คุยด้วย E หรือ Space · ตอบด้วยการคลิก หรือกดเลข 1–4
- แท็บเล็ตและมือถือ: เดินด้วยจอยสติ๊กซ้ายล่าง หรือแตะที่พื้น · แตะปุ่ม 💬 เพื่อคุย

## หน่วยการเรียนรู้ (4 ภูมิภาค)
| ภูมิภาค | หน่วยการเรียนรู้ | ด่าน |
|---|---|---|
| ทุ่งหญ้านักสืบข้อมูล | หน่วยที่ 1 รู้ทันข้อมูล: การสืบค้นและประเมินความน่าเชื่อถือของข้อมูล | 1–8 |
| นครตารางคริสตัล | หน่วยที่ 2 จัดการข้อมูลด้วยโปรแกรมตารางทำงาน | 9–20 |
| ป่าศิลปินสร้างสรรค์ | หน่วยที่ 3 นักสื่อสารวิทยาศาสตร์: ออกแบบและสร้างสรรค์สื่อดิจิทัล | 21–32 |
| เกาะพลเมืองดิจิทัล | หน่วยที่ 4 เทคโนโลยีปลอดภัย เป็นมิตรต่อสิ่งแวดล้อม และพลเมืองดิจิทัล | 33–40 |

## สำหรับครู
- ปุ่ม "สำหรับครู" ที่หน้าแรกใช้ดูผลการเล่นทุกครั้ง และดาวน์โหลดเป็นไฟล์ CSV เพื่อเปิดใน Excel ได้
- ผลการเล่นบันทึกไว้ในเบราว์เซอร์ของเครื่องที่นักเรียนใช้เล่น ถ้าล้างข้อมูลเบราว์เซอร์ ผลจะหายไปด้วย
- ถ้าเครื่องช้า กดปุ่ม "กราฟิก: ประหยัด" ที่หน้าแรก (แท็บเล็ตและมือถือจะใช้โหมดประหยัดตั้งแต่แรก)
- เกมจะอ่านคำถามออกเสียงให้ ถ้าเครื่องมีเสียงภาษาไทย (Windows และ Android ส่วนใหญ่มีอยู่แล้ว)

## แก้ไขคำถาม
คำถามทั้ง 400 ข้อเก็บอยู่ในไฟล์ `u1.js` ถึง `u4.js` (แยกไฟล์ตามหน่วยการเรียนรู้)
คำถามแต่ละข้อเขียนในรูปแบบ `["คำถาม", ["คำตอบที่ถูก", "ตัวเลือกผิด", "ตัวเลือกผิด", "ตัวเลือกผิด"], "คำอธิบาย"]`
ให้ใส่คำตอบที่ถูกไว้เป็นตัวเลือกแรกเสมอ เพราะเกมจะสลับลำดับตัวเลือกให้เองตอนเล่น

## เทคนิค
- ใช้ three.js r160 ซึ่งรวมไว้ในไฟล์ `game.js` แล้ว จึงไม่ต้องดึงไลบรารีจากเว็บภายนอก
- ดนตรีพื้นหลังและเสียงเอฟเฟกต์สร้างด้วย Web Audio จึงไม่มีไฟล์เสียงให้ต้องโหลด
- ตัวละครอัศวิน ผู้ท้าประลอง และปีศาจ ใช้โมเดล 3 มิติจาก KayKit Character Pack: Adventurers และ Skeletons โดย Kay Lousberg (สัญญาอนุญาต CC0 ใช้ได้ฟรีทั้งงานส่วนตัวและเชิงพาณิชย์) แล้วนำมาแต่งเป็นปีศาจด้วยโค้ด (สีตัว ดวงตาเรืองแสง เขา ปีก และออร่า)
- ฉาก ต้นไม้ ประตูมิติ ภูตบิตตี้ และเอฟเฟกต์ต่าง ๆ สร้างด้วยโค้ดทั้งหมด
- ถ้าจะเปิดในเครื่องโดยไม่ใช้ GitHub Pages ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เช่น ส่วนขยาย Live Server ใน VS Code) เพราะเปิดไฟล์ `index.html` ตรง ๆ แบบดับเบิลคลิกจะใช้ไม่ได้
